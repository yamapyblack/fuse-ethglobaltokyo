# Genesis 残り337枚の生成依頼

## ゴール

すでに存在する **663枚と見分けがつかない画風で、残り337枚を作る**こと。
これは1000体のNFTコレクションの一部で、1枚でも浮くと商品として成立しません。
「上手い絵」ではなく「揃った絵」が要件です。

## いちばん確実な方法

**このリポジトリのスクリプトをそのまま動かしてください。** 663枚はこれで作られています。
自前でプロンプトを組み直すと画風がずれます。

```bash
git clone <repo> && cd fuse-ethglobaltokyo/web
git checkout v2
pnpm install
cp .env.example .env.local     # 値はオーナーから受け取る

pnpm check:r2                  # R2の疎通確認（OpenAIは呼ばない）
pnpm list:genesis              # 欠番を確認
CONCURRENCY=5 pnpm gen:genesis # 生成。既存の663枚は自動でスキップされる
```

スクリプトは中断・再実行に耐えます。すでにR2にあるものは飛ばすので、
何度走らせても二重に課金されません。

### 注意点

- **OpenAIのレートリミットは 5枚/分** です。337枚で最低70分かかります。`CONCURRENCY` を
  上げても速くなりません
- クレジット残高を先に確認してください。切れると429が延々と出ます
- R2への接続が断続的に `ENOTFOUND` を返すことがあります。リトライで復帰しますが、
  大量に失敗したら一度止めて、再実行してください

## スクリプトを使えない場合

別のツールで作るなら、以下を**すべて**守ってください。

### 入力

`docs/genesis-missing.json` に337件ぶんの情報が入っています。1件はこの形です。

```json
{
  "tokenId": 246,
  "family": "sushi",
  "base": "Onigiri",
  "mood": "Sleepy",
  "accent": "Lilac",
  "charm": "Blush",
  "pose": "Curled",
  "outputImage": "genesis/images/246.png",
  "outputMetadata": "genesis/246.json",
  "prompt": "Design a cute mascot version of ..."
}
```

`prompt` は663枚に使ったものと同じ組み立てで生成済みです。**そのまま使ってください。**
要約したり言い換えたりしないこと。画風の一貫性はこの文面に依存しています。

### 出力の要件

| 項目 | 要件 |
| --- | --- |
| 解像度 | 1024 × 1024 |
| 形式 | PNG |
| カラーモード | **RGB（不透過）**。アルファチャンネルを残さない |
| 背景 | `#FAF7F2` の単色。四隅まで同じ色 |
| 被写体 | 中央に1体だけ。文字・枠・複数コマは不可 |

**透過で返ってきたら `#FAF7F2` に焼き込んでから保存してください。** 生成APIは指定しても
透過を返すことがあり、不透過のものと混ざるとコレクションとして揃いません。
663枚はすべて焼き込み済みです。

### 検収基準

1枚ごとに機械で判定できます。人手で337枚を見るのは現実的ではないので、必ず自動化してください。

```
1. サイズが 1024x1024 であること
2. カラーモードが RGB（アルファなし）であること
3. 四隅4点の輝度の平均が 225 以上であること
   ← 背景が暗い／透過のまま、を弾く
```

輝度は `0.299R + 0.587G + 0.114B` で計算します。**焼き込んだ後に測ること。**
透過のまま測るとRGBが0になり、黒背景と誤判定します。

検収スクリプトを用意してあります。既存663枚は全件これを通っています。

```bash
DIR=/path/to/your/images pnpm verify:genesis
```

不合格があると tokenId と理由を出し、作り直し用のコマンドまで表示します。
基準を満たさないものは作り直してください。3回外したら、その tokenId を報告して次へ進んでください。

### 提出方法

R2の認証情報があるなら直接アップロードしてください。

```
バケット: fuse-ethglobaltokyo
画像:     genesis/images/{tokenId}.png
```

無い場合は、`{tokenId}.png` というファイル名でzipにまとめて渡してください。
**ファイル名の tokenId が唯一の紐付けです。** 連番を振り直したり、名前を変えたりしないでください。

メタデータJSON（`genesis/{tokenId}.json`）は、画像さえあればこちらのスクリプトで
生成し直せます。作らなくて構いません。

## 参考: 既存の663枚

`pnpm download:genesis` でローカルに落とせます（約800MB）。
画風を合わせる参考にしてください。特に以下を見ておくと外しません。

- 輪郭線の太さと色（濃い紫系で統一）
- 影のつけ方（フラットで、グラデーションは薄く）
- 顔のパーツの大きさ（目は大きめ、口は小さい）
- 背景が完全に平坦で、光背や影が落ちていないこと

## やってはいけないこと

- **プロンプトの書き換え・要約**。画風がずれます
- **tokenId の振り直し**。割り当て表とチェーン上の family がずれ、修復が困難になります
- **レアリティを感じさせる差別化**。全個体が均等である必要があります。
  「せっかくだから特別な1枚を」は不要です
- **画風のアップグレード**。663枚より良く見えても、揃っていなければ不良品です
